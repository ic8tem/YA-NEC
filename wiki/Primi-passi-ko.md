# 시작하기

1. **예제**(명령 막대)로 준비된 모델을 엽니다: 다이폴, 그라운드 플레인, VHF 야기(DK7ZB, I4GBZ, DJ9BV BVO, YU7EF), HF 야기(Force 12 XR-5, ARRL 520-40H), 헥스빔, 포스퀘어, 1296 MHz 루프 야기 등. **모델 열기**로 NEC, MMANA, AutoEZ, EZNEC, K6STI 파일을 엽니다. 파일을 창에 끌어다 놓아도 됩니다.
2. **밴드**(2200 m~3 cm, IARU 1지역 범위) 또는 임의 주파수를 고르고 **계산**을 누릅니다.
3. **결과 칸**에 임피던스, SWR, 이득, F/B, F/R, -3 dB 빔폭, 효율, AGT(수렴 테스트: 0 dB에 가까우면 모델을 신뢰할 수 있음)가 표시됩니다.
4. **스윕**은 주파수 주변 대역을 계산합니다: SWR, R/X, 이득, F/B, 스미스 차트.

## 탭

- **3D 구조**: 안테나(끌기 = 회전, 휠 = 확대, 오른쪽 버튼 = 이동, 더블 클릭 = 처음 보기). 대지는 종류와 높이에 따라 그려집니다. 아래에는 스프레드시트 형식의 **와이어 표**가 있으며 셀에는 숫자, 변수, 수식을 넣을 수 있습니다. 오른쪽 아래는 **모델 객체**: 급전원, 부하, 선로, 변압기.
- **방사 패턴**: 수평, 수직, 3D. -3 dB 각도 표시.
- **주파수, 스미스, 전류**: 스윕 결과와 와이어의 전류.
- **NEC 모델**: 손으로 편집할 수 있는 NEC 카드.
- **변수**와 **최적화 도구**: 치수에 이름을 붙이고 목표(SWR, 이득, F/B, 임피던스 등)에 맞게 프로그램이 바꾸도록 합니다. 매뉴얼에 단계별 예제가 있습니다.
- **계산기**: [계산기](Calcolatori-ko) 참고.
- **수신 안테나**와 **잡음/GT/스택**: 수신 안테나의 RDF, 안테나 온도와 G/T(TANT와 XLGTa 방식, VE7BQH와 DG7YBN 기준 온도), 스택.
- **경고**: 모델에서 발견한 의심스러운 점(너무 짧거나 긴 세그먼트, 대지에 가까운 와이어, 붐비는 접속점). 위쪽 막대의 **검사...** 버튼은 계산 없이 대표적인 입력 오류 42가지를 검사합니다.
- **설정**, **매뉴얼**, **크레디트**. 오른쪽 위: **언어**, **색상**(18가지), **About**.

## 저장

**저장**과 **다른 이름으로 저장**은 모델을 NEC, MMANA, AutoEZ, EZNEC 또는 자체 **.yanec** 형식(설명과 원본 파일도 보관)으로 씁니다.
