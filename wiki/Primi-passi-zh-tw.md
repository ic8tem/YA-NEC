# 入門

1. **範例**（命令欄）打開一個現成模型：偶極子、地網天線、VHF 八木（DK7ZB、I4GBZ、DJ9BV BVO、YU7EF）、HF 八木（Force 12 XR-5、ARRL 520-40H）、六角天線、四方陣、1296 MHz 環形八木等。**打開模型** 可打開 NEC、MMANA、AutoEZ、EZNEC 或 K6STI 檔案；也可以把檔案拖到視窗中。
2. 選擇 **波段**（2200 m 至 3 cm，IARU 第一區範圍）或任意頻率，然後點擊 **計算**。
3. **結果框** 顯示阻抗、駐波比、增益、F/B、F/R、-3 dB 波束寬度、效率和 AGT（收斂測試：接近 0 dB 表示模型可靠）。
4. **掃頻** 計算頻率附近的波段：駐波比、R/X、增益、F/B 和史密斯圓圖。

## 分頁

- **3D 結构**：天線（拖動 = 旋轉，滾輪 = 縮放，右鍵 = 平移，雙擊 = 初始視圖），地面按類型和高度繪制。下方是電子表格樣式的 **導線表**：單元格可輸入數字、變量和公式。右下方是 **模型對象**：激勵源、負載、傳輸線、變壓器。
- **方向圖**：水平、垂直和 3D，並標出 -3 dB 角度。
- **頻率、史密斯、電流**：掃頻結果和導線上的電流。
- **NEC 模型**：可手工編輯的 NEC 卡片。
- **變量** 和 **最佳化工具**：給尺寸命名，讓程式調整它們以達到目標（駐波比、增益、F/B、阻抗……）。手冊中有分步範例。
- **計算器**：見 [計算器](Calcolatori-zh-tw)。
- **接收天線** 和 **噪聲/GT/堆疊**：接收天線的 RDF、天線溫度和 G/T（TANT 與 XLGTa 的方法，VE7BQH 與 DG7YBN 的參考溫度）、天線堆疊。
- **警告**：程式在模型中發現的所有可疑之處（分段過短或過長、導線離地太近、連接點過於擁擠）。頂部欄的 **檢查...** 按鈕無需計算即可檢查 42 種典型輸入錯誤。
- **設定**、**手冊**、**致謝**。右上角：**語言**、**顏色**（18 種方案）和 **關於**。

## 保存

**保存** 和 **另存為** 可將模型寫成 NEC、MMANA、AutoEZ、EZNEC，或程式自有的 **.yanec** 格式（同時保留說明和原始檔案）。
