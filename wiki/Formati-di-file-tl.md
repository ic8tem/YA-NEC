# Mga format ng file

| Format | Nabubuksan | Nase-save | Tala |
|---|---|---|---|
| NEC-2 (.nec) | oo | oo | mga card na GW, GA, GH, GM, GR, GS, GX, GC, GN, LD, EX, TL, NT, FR, SY (variable at formula tulad ng sa 4nec2 at xnec2c) |
| MMANA (.maa) | oo | oo | muling kinakalkula ang segmentation para sa NEC-2 (MININEC engine ang gamit ng MMANA) |
| AutoEZ (.weq) | oo | oo | variable at formula ng Excel |
| EZNEC (.ez) | oo | oo | wire, source, load, linya, lupa; binabasa ang MININEC na lupa bilang GN 3 na may babala |
| YO / AO ni K6STI (.yag, .ant) | oo | hindi | |
| YA-NEC (.yanec) | oo | oo | ang model sa orihinal nitong format, may pangalan, paglalarawan at kategorya |

Naglalaman ang .yanec na file ng model **nang walang conversion** (ang mga NEC card gaya ng dati, ang teksto ng .maa, .weq, .yag, .ant; ang .ez sa base64): binabasa ito ng YA-NEC gamit ang parehong importer ng orihinal na file, kaya pareho ang resulta sa orihinal.

Lahat ng detalye ay nasa kabanata 10 ng manwal.
