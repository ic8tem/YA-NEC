# 자동 업데이트

YA-NEC는 30분마다(그리고 시작 2분 후) 이 GitHub에 공개된 최신 버전을 조용히 확인합니다. 더 새로우면:

1. 해당 플랫폼의 zip과 `.sha256` 체크섬을 내려받고;
2. 체크섬을 확인하여, 없거나 다르면 아무것도 설치하지 않으며;
3. 옛 파일을 새 파일로 바꿉니다. 새 버전은 **다음 실행 시** 적용되며 상태 표시줄에 메시지가 나옵니다.

이전 버전은 직접 되돌릴 수 있도록 `data/aggiornamenti/precedente-<버전>`에 남습니다. 설정(`data/config.ini`), 로그, 사용자 모델은 건드리지 않습니다. YA-NEC 창이 여러 개 열려 있으면 첫 번째 창만 확인합니다.

**설정 > 업데이트**에서 끌 수 있으며 **지금 확인** 버튼은 30분을 기다리지 않습니다. 각 단계는 로그(분류 AGGIORNAMENTO)에 기록됩니다.

**.deb와 .rpm 패키지**(제공될 경우): 관리자 권한으로 설치되며 패키지 관리자(`apt`, `dnf`, `zypper`)로만 업데이트됩니다. 이런 패키지에서는 자동 업데이트가 꺼져 있고 설정 화면에도 그렇게 표시됩니다.
