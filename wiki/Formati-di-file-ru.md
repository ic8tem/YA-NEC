# Форматы файлов

| Формат | Открывает | Сохраняет | Примечания |
|---|---|---|---|
| NEC-2 (.nec) | да | да | карты GW, GA, GH, GM, GR, GS, GX, GC, GN, LD, EX, TL, NT, FR, SY (переменные и формулы как в 4nec2 и xnec2c) |
| MMANA (.maa) | да | да | сегментация пересчитывается для NEC-2 (MMANA использует ядро MININEC) |
| AutoEZ (.weq) | да | да | переменные и формулы Excel |
| EZNEC (.ez) | да | да | провода, источники, нагрузки, линии, земля; земля MININEC читается как GN 3 с предупреждением |
| YO / AO от K6STI (.yag, .ant) | да | нет | |
| YA-NEC (.yanec) | да | да | модель в исходном формате, с названием, описанием и категорией |

Файл .yanec содержит модель **без преобразования** (карты NEC как есть, текст .maa, .weq, .yag, .ant; .ez в base64): YA-NEC читает его тем же импортом, что и исходный файл, поэтому результаты совпадают с оригиналом.

Все подробности в главе 10 руководства.
