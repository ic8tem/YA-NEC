# 入门

1. **示例**（命令栏）打开一个现成模型：偶极子、地网天线、VHF 八木（DK7ZB、I4GBZ、DJ9BV BVO、YU7EF）、HF 八木（Force 12 XR-5、ARRL 520-40H）、六角天线、四方阵、1296 MHz 环形八木等。**打开模型** 可打开 NEC、MMANA、AutoEZ、EZNEC 或 K6STI 文件；也可以把文件拖到窗口中。
2. 选择 **波段**（2200 m 至 3 cm，IARU 第一区范围）或任意频率，然后点击 **计算**。
3. **结果框** 显示阻抗、驻波比、增益、F/B、F/R、-3 dB 波束宽度、效率和 AGT（收敛测试：接近 0 dB 表示模型可靠）。
4. **扫频** 计算频率附近的波段：驻波比、R/X、增益、F/B 和史密斯圆图。

## 标签页

- **3D 结构**：天线（拖动 = 旋转，滚轮 = 缩放，右键 = 平移，双击 = 初始视图），地面按类型和高度绘制。下方是电子表格样式的 **导线表**：单元格可输入数字、变量和公式。右下方是 **模型对象**：激励源、负载、传输线、变压器。
- **方向图**：水平、垂直和 3D，并标出 -3 dB 角度。
- **频率、史密斯、电流**：扫频结果和导线上的电流。
- **NEC 模型**：可手工编辑的 NEC 卡片。
- **变量** 和 **优化器**：给尺寸命名，让程序调整它们以达到目标（驻波比、增益、F/B、阻抗……）。手册中有分步示例。
- **计算器**：见 [计算器](Calcolatori-zh)。
- **接收天线** 和 **噪声/GT/堆叠**：接收天线的 RDF、天线温度和 G/T（TANT 与 XLGTa 的方法，VE7BQH 与 DG7YBN 的参考温度）、天线堆叠。
- **警告**：程序在模型中发现的所有可疑之处（分段过短或过长、导线离地太近、连接点过于拥挤）。顶部栏的 **检查...** 按钮无需计算即可检查 42 种典型输入错误。
- **设置**、**手册**、**致谢**。右上角：**语言**、**颜色**（18 种方案）和 **关于**。

## 保存

**保存** 和 **另存为** 可将模型写成 NEC、MMANA、AutoEZ、EZNEC，或程序自有的 **.yanec** 格式（同时保留说明和原始文件）。
