# はじめに

1. **例**（コマンドバー）で用意されたモデルを開きます：ダイポール、グラウンドプレーン、VHF 八木（DK7ZB、I4GBZ、DJ9BV BVO、YU7EF）、HF 八木（Force 12 XR-5、ARRL 520-40H）、ヘックスビーム、フォースクエア、1296 MHz ループ八木など。**モデルを開く** で NEC、MMANA、AutoEZ、EZNEC、K6STI のファイルを開けます。ファイルをウィンドウにドラッグしても開けます。
2. **バンド**（2200 m〜3 cm、IARU 第 1 地域の範囲）または任意の周波数を選び、**計算** を押します。
3. **結果欄** にインピーダンス、SWR、利得、F/B、F/R、-3 dB ビーム幅、効率、AGT（収束テスト：0 dB に近ければモデルは信頼できる）が表示されます。
4. **スイープ** は周波数の周りのバンドを計算します：SWR、R/X、利得、F/B、スミスチャート。

## タブ

- **3D 構造**：アンテナ（ドラッグ＝回転、ホイール＝ズーム、右ボタン＝移動、ダブルクリック＝初期表示）。大地は種類と高さに応じて描かれます。下には表計算風の **ワイヤー表**。セルには数値、変数、数式を入力できます。右下は **モデルのオブジェクト**：給電点、負荷、線路、トランス。
- **パターン**：水平面、垂直面、3D。-3 dB の角度付き。
- **周波数、スミス、電流**：スイープの結果とワイヤー上の電流。
- **NEC モデル**：手で編集できる NEC カード。
- **変数** と **オプティマイザー**：寸法に名前を付け、目標（SWR、利得、F/B、インピーダンスなど）に向けてプログラムに変えさせます。マニュアルに手順付きの例があります。
- **計算ツール**：[計算ツール](Calcolatori-ja) を参照。
- **受信アンテナ** と **雑音/GT/スタック**：受信アンテナの RDF、アンテナ温度と G/T（TANT と XLGTa の方法、VE7BQH と DG7YBN の基準温度）、スタック。
- **警告**：モデル内の疑わしい点（短すぎる・長すぎるセグメント、大地に近いワイヤー、混み合った接続点）。上部バーの **チェック...** ボタンは計算せずに典型的な入力ミス 42 項目を確認します。
- **設定**、**マニュアル**、**クレジット**。右上：**言語**、**色**（18 種類）、**About**。

## 保存

**保存** と **名前を付けて保存** で、モデルを NEC、MMANA、AutoEZ、EZNEC、または独自の **.yanec** 形式（説明と元ファイルも保持）で書き出せます。
