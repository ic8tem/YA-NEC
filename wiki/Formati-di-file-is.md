# Skráasnið

| Snið | Opnar | Vistar | Athugasemdir |
|---|---|---|---|
| NEC-2 (.nec) | já | já | spjöldin GW, GA, GH, GM, GR, GS, GX, GC, GN, LD, EX, TL, NT, FR, SY (breytur og formúlur eins og í 4nec2 og xnec2c) |
| MMANA (.maa) | já | já | bútun er endurreiknuð fyrir NEC-2 (MMANA notar MININEC-vél) |
| AutoEZ (.weq) | já | já | breytur og Excel-formúlur |
| EZNEC (.ez) | já | já | vírar, lindir, álag, línur, jörð; MININEC-jörð er lesin sem GN 3 með viðvörun |
| YO / AO frá K6STI (.yag, .ant) | já | nei | |
| YA-NEC (.yanec) | já | já | líkanið á upprunalegu sniði, með nafni, lýsingu og flokki |

.yanec-skráin inniheldur líkanið **án umbreytingar** (NEC-spjöldin eins og þau eru, texti .maa, .weq, .yag, .ant; .ez í base64): YA-NEC les hana með sama innflytjanda og upprunalegu skrána, svo niðurstöðurnar eru þær sömu og frumritsins.

Öll smáatriði í 10. kafla handbókarinnar.
